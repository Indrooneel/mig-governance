# Security Policy

## Reporting a Vulnerability

MIG Governance is a security tool. We take vulnerabilities seriously.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Email: **neel@houseofgalatine.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

Response within 48 hours.

## Scope

This policy covers the mig-governance SDK codebase in this repository.

## Responsible Disclosure

- Give us reasonable time to fix before public disclosure
- Do not exploit beyond what is necessary to demonstrate
- Do not access or modify other users' data
